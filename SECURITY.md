# Segurança

## Relatando uma vulnerabilidade

Não publique vulnerabilidades em issues abertas. Use **Security > Report a
vulnerability** no GitHub ou entre em contato diretamente com o responsável
pelo repositório.

Inclua passos de reprodução, impacto e a versão afetada. Evite anexar chaves,
bancos, vídeos de clientes ou outros dados pessoais.

## Dados locais

O Klipe é executado localmente. Chaves opcionais ficam em variáveis de ambiente
ou configurações locais ignoradas pelo Git. Antes de expor o servidor em uma
rede, revise autenticação, firewall e permissões de pasta.
